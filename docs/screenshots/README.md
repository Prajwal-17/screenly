# UI captures

These images are browser screenshots of the rebuilt Screenly application, generated by `CAPTURE_SCREENSHOTS=1 bun run test:e2e`. They use local controlled LLM and Deepgram protocol fixtures with simulated microphone input. Text, scores, account names, and timings are test data. They demonstrate presentation and behavior, not live-provider quality.

Desktop routes cover landing, authentication, overview, setup, preflight, live interview, feedback, and history. Additional captures cover the active interview at 1440 and 1536px, history at 640px, and setup, navigation, live voice, and feedback at 360px. No screenshot or generated raster is used as a runtime frontend asset.
